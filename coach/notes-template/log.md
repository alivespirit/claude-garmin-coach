# Workout log

Oldest first. The coach adds an entry after each analysis and condenses entries older than
4 weeks into one summary per week. The whole file is loaded on every run, so keep it under
~150 lines.

## Week YYYY-MM-DD–MM-DD (condensed)
- Key sessions and the main conclusion, in 1–2 lines.

## YYYY-MM-DD — Workout name (activity id)
- Key numbers: distance, pace, HR; per-rep pace and HR for intervals.
- Context: weather, terrain, sleep and readiness, fueling.
- Decision: what changes in the plan, if anything.
